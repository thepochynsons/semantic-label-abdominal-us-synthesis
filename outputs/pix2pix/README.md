# Pix2Pix outputs

Place representative Pix2Pix Stage I outputs here. Whenever possible, use filenames that share a stem with the corresponding files in `data/test_labels/` and `data/test_references/`.

Recommended naming pattern:

```text
<volume_id>_<sample_id>_pix2pix.<ext>
```

Do not add outputs whose provenance, checkpoint, split, or preprocessing convention cannot be identified. A manifest describing the included examples should be added when the images are available.
