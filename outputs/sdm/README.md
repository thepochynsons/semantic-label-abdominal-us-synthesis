# Semantic Diffusion Model outputs

Place representative SDM Stage I outputs here. Include the denoising-step count in the filename or in a companion manifest when multiple inference settings are shown.

Recommended naming pattern:

```text
<volume_id>_<sample_id>_sdm_steps-<N>.<ext>
```

Whenever possible, filenames should share a stem with the corresponding files in `data/test_labels/` and `data/test_references/`.
