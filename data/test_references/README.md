# Representative physics-based references

This directory contains the physics-based ultrasound reference images corresponding to the representative semantic label maps in [data/test_labels/](../test_labels/).

The included examples are:

| File | Source dataset | Description |
| --- | --- | --- |
| `resized_ct20-29.png` | VISCERAL Anatomy3 | Physics-based ultrasound image generated from the corresponding VISCERAL semantic label/CT input. |
| `resized_ircad17-3.png` | IRCAD 3D-IRCADb-01 | Physics-based ultrasound image generated from the corresponding IRCAD input, including the pathological example with a tumor. |

These images were generated with the physics-based ultrasound simulation model described by Vitale et al. in [Improving realism in patient-specific abdominal ultrasound simulation using CycleGANs](https://link.springer.com/article/10.1007/s11548-019-02046-5). The simulator is based on the ray-casting approach introduced by Shams et al. in [Real-time simulation of medical ultrasound from CT images](https://link.springer.com/chapter/10.1007/978-3-540-85990-1_88)

The references in this directory are synthetic physics-based images, not real ultrasound acquisitions and not outputs generated by the Pix2Pix or Semantic Diffusion Model Stage I networks.
